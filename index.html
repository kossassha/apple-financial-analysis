Data & Methodology

How the Analysis Was Built

Financial metrics are calculated from Apple fiscal-year financial statements using Python and Pandas.

01

Data Source

Financial data was collected from Apple Inc. annual Form 10-K filings published through the U.S. Securities and Exchange Commission EDGAR system.

Apple Form 10-K FY2021
Apple Form 10-K FY2023
Apple Form 10-K FY2025
02

Data Processing

Raw financial statement values are stored in CSV format and processed using Python and Pandas before being displayed by the dashboard.

Raw CSV → Python → JSON → Dashboard
03

Calculated Metrics

Analytical indicators are calculated programmatically rather than entered manually into the dashboard.

Net Margin Net Income / Revenue × 100
Free Cash Flow Operating Cash Flow − CapEx
FCF Margin Free Cash Flow / Revenue × 100
Debt / Assets Total Debt / Total Assets
Cash / Debt Cash / Total Debt
Revenue CAGR (Ending / Beginning)^(1/n) − 1
