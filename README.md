# Apple Financial Analysis Dashboard

An interactive financial analysis dashboard for Apple Inc. covering fiscal years 2021–2025.

The project combines financial statement analysis, Python-based data processing, calculated financial metrics and an interactive web dashboard.

---

## Overview

The goal of this project is to analyze Apple Inc.'s financial performance over a five-year period and present the results in a clear and interactive format.

The analysis focuses on:

- Revenue growth
- Net income
- Profitability
- Free cash flow
- Capital expenditures
- Assets
- Debt
- Liquidity
- Financial ratios
- Long-term financial trends

The dashboard is built as a standalone website using HTML, CSS, JavaScript and Chart.js.

Financial calculations and data preparation are performed using Python and Pandas.

## Key Features

### Financial Overview

The dashboard displays key financial indicators for the latest fiscal year:

- Revenue
- Net Income
- Net Margin
- Free Cash Flow
- Year-over-year changes

---

### Revenue & Net Income Analysis

Interactive chart showing the development of:

- Revenue
- Net Income

from FY2021 to FY2025.

---

### Profitability Analysis

The profitability section tracks:

- Gross Margin
- Operating Margin
- Net Margin

This makes it possible to evaluate how efficiently the company converts revenue into profit.

---

### Balance & Liquidity

The dashboard compares:

- Total Assets
- Total Debt
- Cash

to provide an overview of Apple's financial position.

---
